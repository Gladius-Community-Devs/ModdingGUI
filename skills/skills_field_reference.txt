# ============================================================
# GLADIUS SKILLS.TOK — FIELD REFERENCE
# ============================================================
# Purpose: document every field in skills.tok, their known
#          static value lists, and how fields relate to each
#          other, so the GUI schema can be built correctly.
#
# Edit this file, then hand it back.  Do not change the
# FIELD:/FORMAT:/MULTI:/VALUES:/LINK:/REQUIRES:/NOTES:/--- 
# keywords — only edit the content after the colon.
#
# ============================================================
# FORMAT GUIDE
# ============
#
# Each field block uses these keys (all optional except FIELD):
#
#   FIELD:    <FIELDNAME>
#   FORMAT:   plain-English description of the value structure
#   MULTI:    yes / no   — can this line appear more than once per skill record?
#   VALUES:   value1 | value2 | value3
#             (enum fields only; pipe-separated; wrap to next line with leading spaces)
#   LINK:     <OTHER_FIELD>
#             Both fields must appear together whenever either one is present.
#             Symmetric — only write the link on one side.
#             Add one LINK: line per linked field.
#   REQUIRES: <condition>
#             This field only appears when a condition on another field is true.
#             The other field CAN exist without this one.
#   NOTES:    free text — anything useful
#   ---       (three dashes ends the block)
#
# --------------------------------------------------------
# CONDITION SYNTAX FOR REQUIRES:
#
#   FIELD present                  field exists at all
#   FIELD = value                  field equals a specific value
#   FIELD.part = value             a sub-part of the field equals a value
#                                  (use for comma-structured fields, e.g.
#                                   SKILLCREATE.type = Attack)
#   FIELD.name = value             for effect/status fields, the name sub-part
#
# --------------------------------------------------------
# EXAMPLES (filled-out blocks for illustration):
#
#   FIELD:    SKILLAFFCOST
#   FORMAT:   integer; divide by 20 to get actual orb cost
#   MULTI:    no
#   VALUES:
#   LINK:     SKILLAFFINITY
#   REQUIRES:
#   NOTES:    always paired with SKILLAFFINITY
#   ---
#
#   FIELD:    SKILLAFFINITY
#   FORMAT:   "value"
#   MULTI:    no
#   VALUES:   Air | Dark | Earth | Fire | Light | None | Water
#   LINK:     SKILLAFFCOST
#   REQUIRES:
#   NOTES:
#   ---
#
#   FIELD:    SKILLMOVERANGE
#   FORMAT:   range, "pattern"
#   MULTI:    no
#   VALUES:
#   LINK:
#   REQUIRES: SKILLATTRIBUTE = teleport
#   NOTES:    only present when the teleport attribute is set
#   ---
#
# ============================================================
# FIELDS ARE GROUPED BY ROLE.
# If a field belongs to more than one group, it appears in the
# most relevant one with a cross-reference in NOTES.
# ============================================================

REQUIRES:
NOTES:    The name must be unique across the file.
          type and category are always present (both quoted).

# ============================================================
# GROUP 3 — TARGETING AND RANGE
# ============================================================

FIELD:    SKILLRANGE
FORMAT:   range, "pattern"
MULTI:    no
VALUES[pattern]: Diamond | Linear | Plus | Plus2x2 | Plus3x3 | Self | Square | Square2x2 | Star
LINK:
REQUIRES:
NOTES:    range = integer tile count.
          When range = 0 and pattern = "Self", the skill uses SKILLEFFECTRANGE
          instead to define its AoE footprint.
---

FIELD:    SKILLEXCLUDERANGE
FORMAT:   range, "pattern"
MULTI:    no
VALUES[pattern]: Diamond | Linear | Plus | Plus2x2 | Plus3x3 | Self | Square | Square2x2 | Star
LINK:
REQUIRES: SKILLRANGE
NOTES:    Tiles excluded from targeting (minimum distance).
---

FIELD:    SKILLEFFECTRANGE
FORMAT:   range, "pattern"
MULTI:    no
VALUES[pattern]: Cone | Linear | Plus3x3 | Self | SourceCone | SourceDiamond | SourceLinear
                 SourceSquare | Square | Square2x2 | SrcLinear2x2 | SrcLinear3x3
LINK:     
REQUIRES:
NOTES:    Defines the AoE footprint originating from the targetted tile.
			Self is for applying the skill to the caster, typically used on Support skills
---

FIELD:    SKILLEFFECTCONDITION
FORMAT:   string (see VALUES)
MULTI:    yes
VALUES:   friend only | friend only not self | enemy only | all units not self
          targetstatus req <status> | targetstatus ign <status>
LINK:     
REQUIRES:
NOTES:    Filters which units are actually affected by the skill.
          "targetstatus req/ign <status>" uses a status name (see SKILLSTATUS names).
---

FIELD:    SKILLTARGETCONDITION
FORMAT:   string (see VALUES)
MULTI:    yes
VALUES:   all units not self | any square | empty square | enemy only
          friend only | friend only not self | self only

          sourcestatus req woundedquarter
LINK:
REQUIRES:
NOTES:    Restricts which squares/units can be chosen as the skill target.
---

FIELD:    SKILLUSABILITYCONDITION
FORMAT:   string (see VALUES)
MULTI:    yes
VALUES:   sourcestatus req berserk | targetstatus req berserk | targetstatus req woundedquarter
LINK:
REQUIRES:
NOTES:    Condition on the SOURCE unit (or target) that must be true for the skill
          to appear as usable in the menu.
---


# ============================================================
# GROUP 4 — COMBAT MECHANICS
# ============================================================

FIELD:    SKILLATTRIBUTE
FORMAT:   string (see VALUES)
MULTI:    yes
VALUES:   affinity | cantmiss | charge | melee | movetoattack | noninterface
          okwithnotargets | piercing | ranged | shield | spell | suicide | teleport | weapon
LINK:
REQUIRES:
NOTES:    Each attribute line adds one attribute to the skill.
          "weapon" = uses equipped weapon and applies weapon item skills; "shield" = uses equipped shield.
          "teleport" requires SKILLMOVERANGE to also be present.
          "movetoattack" requires SKILLMOVETOATTACKMOD to also be present.
---

FIELD:    SKILLCOMBATMODS
FORMAT:   accuracy_modifier, damage_multiplier
MULTI:    no
VALUES:
LINK:
REQUIRES:
NOTES:    accuracy_modifier: integer added to hit chance (0 = normal accuracy).
          damage_multiplier: float; 1.0 = 100% of base damage.
---

FIELD:    SKILLMULTIHITDATA
FORMAT:   string of position letters per hit (see VALUES)
MULTI:    yes
VALUES[letters]: A=front-left | B=in-front | C=front-right | D=right
                 E=back-right  | F=behind   | G=back-left   | H=left
LINK:
REQUIRES:
NOTES:    One SKILLMULTIHITDATA line per hit in the multi-hit sequence.
          Each line is a string of letters indicating which adjacent tiles
          that hit affects (e.g. "BC" hits the tile in front and front-right).
---

FIELD:    SKILLMOVETOATTACKMOD
FORMAT:   integer
MULTI:    no
VALUES:
LINK:
REQUIRES: This is a required line prior to SKILLMOVETOATTACKMOD: SKILLATTRIBUTE = "movetoattack"
NOTES:    Extra (+) or reduced (-) movement tiles available when using
          Move-to-Attack with this skill.
---

FIELD:    SKILLMETER
FORMAT:   "type", base_value, max_or_step_value
MULTI:    no
VALUES[type]: Basic | Bounce1 | Bounce2 | Breakout | Chain | ChainSlow
              FastButton1 | FastButton2 | FastButton3 | Loop1 | Loop2 | None
              Pound1 | Pound2 | Pound3 | Precision1 | Precision2 | Precision3
LINK:
REQUIRES:
NOTES:    Controls the timing minigame shown during the skill.
          For Chain/ChainSlow: third value = total number of hits in the combo.
          When type = Chain or ChainSlow, SKILLSUBSKILL should also be present.
---

FIELD:    SKILLSUBSKILL
FORMAT:   "skill name"
MULTI:    no
VALUES:
LINK:
REQUIRES:
NOTES:    Name of the next skill in a combo chain.
          That skill record has its own SKILLCREATE, SKILLCOMBATMODS, etc.
          Add REQUIRES/LINK here once combo linking rules are confirmed.
---

FIELD:    SKILLCOMBOBUTTON
FORMAT:   "button"
MULTI:    no
VALUES:   rdown | rleft | rright | rup
LINK:
REQUIRES: A ComboChain ability that calls `SKILLSUBSKILL: "CLASS ComboChain ##"` 
NOTES:    The button input that triggers this combo step.
          Only appears in Combo and ComboChain skills. It denotes which button on the face buttons will be hit at this step.
---


# ============================================================
# GROUP 5 — EFFECTS
# Effects fire at the moment the skill resolves on the target.
# SKILLEFFECTSKILLCOND and SKILLEFFECTSTATUSCOND are conditions
# that gate whether the effect fires at all.
# ============================================================

FIELD:    SKILLEFFECT
FORMAT:   "name", chance, value
MULTI:    yes
VALUES[name]: Avoid | Block | Change Crowd Source | Change Crowd Target
              Change HP Absolute | Change HP Relative | Change Stack Relative
              Counterattack | Divvy Up HP | Group Attack | Helmet Break
              Knockback | Knockdown | Random Teleport | Remove Status | Retreat
              Shield Block | Shield Break | Shield Restore | ShiftReturn | ShiftTo
              Status Only | Summon | Vampiric HP
              change off affinity | drain either affinity
LINK:
REQUIRES:
NOTES:    chance = integer 0-100 (percentage).
          value  = integer or float depending on the effect name.
          Multiple SKILLEFFECT lines = multiple effects applied on hit.
          "Summon" requires SKILLSUMMONDATA.
          "ShiftTo" / "ShiftReturn" requires SKILLSHIFTDATA.
---

FIELD:    SKILLEFFECTSKILLCOND
FORMAT:   string (see VALUES)
MULTI:    yes
VALUES:   skill: <skill name> | skillattr ign affinity | skillattr ign spell
          skillattr req melee | skillattr req piercing | skillattr req ranged | skillattr req spell
LINK:
REQUIRES:
NOTES:    Condition in order to trigger an effect. For example, an attack that only poisons if the user uses a specific set of skills they have learned.
---

FIELD:    SKILLEFFECTSTATUSCOND
FORMAT:   string (see VALUES)
MULTI:    yes
VALUES:   statuscond all | statuscond bleeding | statuscond blind | statuscond charmed
          statuscond confused | statuscond debuff | statuscond doom | statuscond poison
          statuscond root | statuscond shieldmelt | statuscond stunned
LINK:
REQUIRES:
NOTES:    Status the TARGET must have for SKILLEFFECT to fire.
---

FIELD:    SKILLSPLITEFFECT
FORMAT:   "name", value
MULTI:    no
VALUES[name]: Change HP Relative
LINK:     
REQUIRES:
NOTES:    Like SKILLEFFECT but combines with SKILLSPLITEFFECTCONDITION to allow a skill to do multiple things.
          Value in quotations can match anything SKILLEFFECT can use, numeric value influences the SKILLEFFECT e.g.:
		  SKILLSPLITEFFECT: "Shield Restore", 100, 1 < 100% chance to restore shieldmelt
		  SKILLSPLITEFFECT: "Change HP Relative", -0.1 < decreases targets hp by 10%
---

FIELD:    SKILLSPLITEFFECTCONDITION
FORMAT:   "class: ClassName" | "self only" | "enemy only"
MULTI:    yes
VALUES:
LINK:     
REQUIRES: SKILLSPLITEFFECT
NOTES:    The condition that triggers the split behaviour.
          This can be used to get different effects on units depending on the value being evaluated.
---


# ============================================================
# GROUP 6 — STATUS APPLICATION (SLOT 1)
# These fields define the first status effect the skill applies.
# All "2" variants in Group 7 are a second independent slot.
# ============================================================

FIELD:    SKILLSTATUS
FORMAT:   "name", chance, value
MULTI:    yes
VALUES[name]: always face | ambush interrupt | ambush | auto regen | berserk
              bleeding | blind | change accuracy | change defense | change initiative
              change initiative percent | change moverate | change power percent
              combatattack damagemult | combatdefend damagemult | crowd positive mult
              frozen | hpregen | hpregen noncummulative | immortal | immunity counters
              immunity status | mult def affinity charge rate | mult off affinity charge rate
              mult shield effectiveness | petrification | poison | root | set step up limit
              shieldmelt | simple counterattack | skill meta range add | stun | summon
              supercharge
LINK:
REQUIRES:
NOTES:    Skill Statuses

SKILLSTATUS: "status", 100, 1

Status is from option below, 100 is chance to apply, 1 is dependent on the effect. You can also do SKILLSTATUS2: "status", 100, 1 to add a second status to a skill

hpregen noncumulative - hp regen, 1 is how much per tick (not sure what noncumulative means)
damage multiply - didn't play with this one, i assume just a flat damage multiplier buff/debuff though (either damage done or damage taken)
set step down limit - how far down you can jump (not really used), 1 is how much
set step up limit - how far up you can jump, 1 is how much (used on cats). Only really works on innates.
change off affinity charge rate - flat change to how much affinity you gain offensively.
mult off affinity charge rate - percent change to how much affinity you gain offensively.
change def affinity charge rate - flat change to how much affinity you gain defensively
mult def affinity charge rate - percent change to how much affinity you gain defensively
bleeding - damage over time, 1 is how much per interval
poison - damage over time, 1 is how much per interval
shieldmelt - damage over time to shield, 1 is how much per tick
confusion - give confusion status, 1 does nothing
blind - give blind status, 1 does nothing
charm - give charm status, 1 does nothing
fear - give fear status, 1 does nothing
berserk - give berserk status, 1 does nothing
root - give root status, 1 does nothing
petrification - petrify status, 1 does nothing
frozen - frozen status, 1 does nothing
stun - stun status, 1 does nothing
summon - adds the summon status to a summoned creature (which is the status that allows it to remain in the world), 1 does nothing
supercharge - Ursula and Valens' power up skill. 1 does nothing
immortal - grants immortal status, 1 does nothing
doom count - sets doom status, 1 is how many counts of doom (i believe auto-goes down on target's turn)
ambush - basically just cover from archers, i don't think 1 does anything (maybe lets you fire multiple times per ambush?)
ambush interrupt - the "back off" skills, stops the enemy movement as well as ambushes. i don't think 1 does anything (maybe lets you fire multiple times per ambush?)
conditional activate - used in skills like berserker adrenaline that has a condition (like half health) to activate. Requires a subskill to know what to do when the condition is met. The 1 does nothing
always face - always face target, 1 does nothing. Only seems to work on innates
mult shield effectiveness - Multiply shield health, 1 is how much
dropped item chance up - multiply dropped item chance (chance per item to drop when chests can drop), 1 is how much
combatattack damagemult - increase/decrease by % the damage a gladiator does. 1 is the %
combatdefend damagemult - increase/decrease by % the damage a gladiator takes. 1 is the %
combatattack critmult - increase/decrease by % the damage a gladiator does in a crit. 1 is the %
combatdefend critmult - increase/decrease by % the damage a gladiator takes in a crit. 1 is the %
combatdefend defenseadd - flat add or remove a gladiator's defense, 1 is the number
combatattack accuracyadd - flat add or remove a gladiator's accuracy, 1 is the number
combatdefend face front mult - increase/decrease by % the damage a gladiator takes from the front. 1 is the %
combatattack face front mult - increase/decrease by % the damage a gladiator does from the front. 1 is the %
combatdefend face back mult - increase/decrease by % the damage a gladiator takes from the back. 1 is the %
combatattack face back mult - increase/decrease by % the damage a gladiator does from the back. 1 is the %
crowd no flubs - makes it so if you flub a meter, the crowd doesn't care, 1 does nothing
crowd positive mult - multiplies the change to crowd meters you do, 1 is percent
auto regen - set HP regen, number is amount of heal per tick
simple counterattack - grants a .4 damage counter (used on the counter accessories, doesn't require any subskill). 1 is how many counters you do.
immunity status - sets an immunity to a status (which is determined in skillstatuscondition)
immunity counters - immune to counter attacks, 1 does nothing
skill meta cost add - removes or adds SP cost to skills (only seems to work in innates). 1 is by how much in, 10 per SP.
skill meta range add - removes or adds range for targeting, only seems to work in innates. 1 is by how much.
skill meta effect range add - removes or adds area for AoE attacks, only seems to work in innates. 1 is by how much.
skill meta effect mult - not entirely sure, but i think it adds or removes based on the effect (so like, you could make knockback do 2 squares instead of 1), only likely to work in innates. 1 is by how much.
skill meta stack cost mult - removes or adds stack cost to skills (like pass being a half cost turn, you could make it a quarter turn with this), only seems to work in innates. 1 is by how much.
skill meta status duration mult - removes or adds duration to skills, only seems to work in innates. 1 is by how much.
skill meta status effect mult - removes or adds effects on skills (like making poison do more), only seems to work in innates. 1 is by how much. Not sure on this one honestly

All of the below are pretty much the same, either change by a flat number or a %, the 1 is either the flat number or percent to change by.
change moverate
change moverate percent
change power
change power percent
change accuracy
change accuracy percent
change defense
change defense percent
change initiative
change initiative percent
change movetoattack
change movetoattack percent
          See SKILLSTATUSTARGET, SKILLSTATUSDURATION etc for the rest of slot 1.

          Stack types: value is a count or multiplier.
          Turns types: value is number of turns.

MULTI:    no

          statuscond confused | statuscond doom | statuscond feared | statuscond frozen
          statuscond petrified | statuscond poison | statuscond root | statuscond stunned

			SKILLSTATUS: "immunity status", 0, 0
